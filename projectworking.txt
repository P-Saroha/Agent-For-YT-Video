## 🎯 Project Overview

**YouTube AI Assistant** is a sophisticated Chrome extension powered by Google's Gemini AI that allows users to ask questions about YouTube video content and get intelligent, contextual answers.

### Core Functionality:
- **🎥 Video Analysis**: Extracts and processes YouTube video transcripts
- **🤖 AI Question-Answering**: Uses Google Gemini AI for intelligent responses
- **🔍 Vector Search**: Implements semantic search using embeddings
- **💬 Chat Interface**: Real-time Q&A with beautiful Markdown rendering
- **⚡ Performance**: Optimized for Chrome extension environment

## 🔄 Data Flow

### **Complete Video Processing Workflow:**

```
1. USER ACTION
   │
   ├── User opens YouTube video
   ├── Clicks extension icon
   └── Clicks "Process Video"
   │
   ▼
2. EXTENSION PROCESSING
   │
   ├── Extract video ID from URL
   ├── Send request to server
   └── Show loading indicator
   │
   ▼
3. SERVER PROCESSING
   │
   ├── Check if video already cached
   ├── If cached: return cached data
   └── If not cached: continue processing
   │
   ▼
4. TRANSCRIPT EXTRACTION
   │
   ├── Call YouTube Transcript API
   ├── Try English first
   ├── Fallback to available languages
   ├── Handle auto-generated vs manual
   └── Combine transcript chunks
   │
   ▼
5. TEXT CHUNKING
   │
   ├── Split transcript into chunks
   ├── Apply size limits (500-800 chars)
   ├── Maintain context overlap
   └── Create Document objects
   │
   ▼
6. VECTOR PROCESSING
   │
   ├── Generate embeddings using HuggingFace
   ├── Store in Chroma vector database
   ├── Create similarity search index
   └── Prepare retrieval chain
   │
   ▼
7. AI CHAIN SETUP
   │
   ├── Initialize Gemini AI model
   ├── Create custom prompt template
   ├── Setup RetrievalQA chain
   └── Configure response parameters
   │
   ▼
8. RESPONSE TO EXTENSION
   │
   ├── Return processing status
   ├── Include video metadata
   └── Enable question interface
```

### **Question Answering Workflow:**

```
1. USER QUESTION
   │
   ├── User types question
   ├── Extension shows typing indicator
   └── Sends question to server
   │
   ▼
2. SEMANTIC SEARCH
   │
   ├── Convert question to embeddings
   ├── Search vector database
   ├── Find top 5 similar chunks
   └── Prepare context for AI
   │
   ▼
3. AI PROCESSING
   │
   ├── Send context + question to Gemini
   ├── Apply custom prompt template
   ├── Generate intelligent response
   └── Include source references
   │
   ▼
4. RESPONSE FORMATTING
   │
   ├── Parse AI response
   ├── Format as Markdown
   ├── Include confidence score
   └── Add metadata
   │
   ▼
5. EXTENSION DISPLAY
   │
   ├── Remove typing indicator
   ├── Parse Markdown with Marked.js
   ├── Apply syntax highlighting
   └── Display beautiful response
```

## 🧠 AI Processing Pipeline

### **LangChain Integration:**
```python
# 1. Model Initialization
llm = ChatGoogleGenerativeAI(
    model="gemini-2.5-flash",
    google_api_key=api_key,
    temperature=0.3,
    convert_system_message_to_human=True
)

# 2. Embeddings Setup
embeddings = HuggingFaceEmbeddings(
    model_name="paraphrase-multilingual-MiniLM-L12-v2",
    model_kwargs={'device': 'cpu'},
    encode_kwargs={'normalize_embeddings': True}
)

# 3. Vector Store Creation
vectorstore = Chroma.from_documents(
    documents=chunks,
    embedding=embeddings,
    persist_directory=temp_dir
)

# 4. Retrieval Chain
qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=vectorstore.as_retriever(
        search_type="similarity",
        search_kwargs={"k": 5}
    ),
    chain_type_kwargs={"prompt": custom_prompt},
    return_source_documents=True
)
```

### **Custom Prompt Template:**
```python
prompt_template = """
You are a helpful AI assistant that answers questions about YouTube video content.
You have been provided with relevant excerpts from a video transcript that may be in Hindi or other languages.

Instructions:
- Answer the question in English based on the provided context
- If the transcript is in Hindi or another language, translate and explain the content in English
- Be accurate and specific, using information directly from the transcript
- If the context doesn't contain enough information, say so clearly
- Provide complete, detailed answers (not just fragments)
- For summary requests, provide comprehensive overviews of the main topics

Context from video transcript:
{context}

Question: {question}

Detailed English Answer:
"""
```

## 🔧 Troubleshooting Guide

### **Common Issues & Solutions:**

#### **🚫 Extension Not Loading**
```
Problem: Extension icon doesn't appear
Solutions:
1. Check Developer Mode is enabled
2. Reload extension in chrome://extensions/
3. Check manifest.json syntax
4. Verify all files are present
5. Check browser console for errors
```

#### **🔌 Server Connection Failed**
```
Problem: Cannot connect to API server
Solutions:
1. Verify server is running on port 8000
2. Check CORS configuration
3. Verify API_BASE_URL in popup.js
4. Check network connectivity
5. Review server logs for errors
```

#### **🤖 AI Responses Not Working**
```
Problem: Questions return errors or empty responses
Solutions:
1. Verify GEMINI_API_KEY is set correctly
2. Check API key permissions in Google Console
3. Verify model name is correct (gemini-2.5-flash)
4. Check server logs for API errors
5. Test with simple questions first
```

#### **📺 Video Processing Fails**
```
Problem: Cannot process YouTube videos
Solutions:
1. Verify video has available transcripts
2. Check video is not private/restricted
3. Try different video IDs
4. Check transcript API limits
5. Verify YouTube URL format
```

#### **💾 Memory Issues**
```
Problem: Extension uses too much memory
Solutions:
1. Clear extension cache
2. Restart Chrome
3. Check cache size limits
4. Verify cleanup is working
5. Update to latest version
```
