## 🚀 How to Use These Features

### For Development
```bash
# Install dependencies
make install

# Run tests
make test

# Check code quality
make lint

# Format code
make format

# Run locally
make dev
```

### For Docker
```bash
# Build image
make docker-build

# Run with compose
make docker-run

# View logs
make docker-logs

# Stop
make docker-stop
```

### For CI/CD
1. Push code to GitHub
2. Automatic pipeline runs
3. Tests, linting, security checks
4. Docker image builds
5. Deploy on main branch
